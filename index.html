Cidade Neon

Partida pausada — continue de onde parou.

Explore as ruas iluminadas e complete sua entrega com o menor número de movimentos.

  • Use as setas para mover o personagem.
  • Segure Shift enquanto usa uma seta para correr.
  • Entre no quadrado amarelo da loja para retirar a encomenda.
  • Depois, leve a encomenda ao ponto verde para concluir a entrega.
  • Pressione R para reiniciar a missão.
  • No menu, escolha Continuar para retomar ou Nova partida para recomeçar.
  • Pressione Esc para voltar ao menu sem perder o progresso da partida.
  • Cada entrega concluída rende R$ 50 de dinheiro fictício.
  • Após concluir uma entrega, pressione N para iniciar a próxima.
  • Você tem 60 segundos para retirar e entregar cada encomenda.
  • Se o tempo acabar, pressione R para tentar novamente.
